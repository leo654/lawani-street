Installing Webfonts

1. Upload the files from this zip to your domain.
2. Add this code to your website:

@font-face {
    font-family: 'Baqoos-Woqna-Duo';
    src:url('Baqoos-Woqna-Duo.woff') format('woff'),
        url('Baqoos-Woqna-Duo.woff2') format('woff2'),
        url('Baqoos-Woqna-Duo.eot'),
        url('Baqoos-Woqna-Duo.eot?#iefix') format('embedded-opentype'),
        url('Baqoos-Woqna-Duo.otf') format('truetype');

    font-weight: normal;
    font-style: normal;
    font-display: swap;
}
3. Integrate the fonts into your CSS:
Add the font name to your CSS styles. For example:

h1 { 
   font-family: 'Baqoos-Woqna-Duo';
}  

Troubleshooting Webfonts
1. You may be using the fonts on different domain or subdomain.
2. Check if you have link the fonts properly in the CSS.
